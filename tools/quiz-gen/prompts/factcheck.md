# 근거 대조 프롬프트

`pnpm quiz risk <파일>` 이 골라낸 **위험도 높은 문항**만 대상으로 한다.
전부 검색하면 비용이 크고, 대부분의 문항은 확인이 필요 없다.

## 왜 필요한가

교차 검증은 자기참조라 사실 오류를 못 잡는다.
**외부 자료를 실제로 가져와 대조하는 것**만이 사실 검증이다.
근거 없는 판단은 미탐뿐 아니라 **오탐도 낸다** — 실제로 멀쩡한 해설을
위험하다고 잘못 지적한 적이 있다 (DECISIONS D29).

## 지시

각 문항에 대해:

1. **검증할 주장을 추출한다.** 지문·정답·해설에서 사실로 단정하는 문장.
   특히 **해설의 오류가 가장 위험하다** — 아이가 그대로 배운다.
2. **웹 검색으로 확인한다.** 신뢰할 수 있는 출처(정부기관, 교과서 관련 자료,
   공신력 있는 언론)를 우선한다.
3. **판정한다.**
   - `일치` — 그대로 둔다
   - `부정확` — 틀리지는 않았으나 오해를 부를 수 있다. 문구를 고친다
   - `오류` — 사실과 다르다. 문항을 고치거나 버린다

## 특히 확인할 것

- **안전 정보** — 틀리면 아이가 위험해진다. 소화 방법, 전기 취급, 약품
- **수치** — 주기, 온도, 비율. 교과서 표기와 다를 수 있다
- **정의** — 초등 수준의 단순화가 사실을 왜곡하지 않는지
- **단정 표현** — "항상", "반드시" 에 반례가 없는지

## 출력

문항마다 판정 / 근거 URL / 고칠 문구를 적는다. 고친 뒤 기록:

```
review.factCheck = { passed: true, source: "웹 검색", at: "YYYY-MM-DD", note: "무엇을 확인했는지" }
```
