# 교차 검증 프롬프트

`pnpm quiz blind <파일>` 이 출력한 **정답이 지워진 문항 목록**을 입력으로 쓴다.

## 지시

당신은 이 문제들을 처음 보는 학생이자 채점자다.
아래 문항을 **하나씩 풀고** 정답 번호를 고르라.

- 문제를 만든 사람의 의도를 추측하지 말고, **내용만 보고** 판단하라.
- 정답이 둘 이상으로 읽히면 그 사실을 따로 적어라 — 그것 자체가 결함이다.
- 확신이 없으면 확신 없음을 표시하라.

## 출력

JSON 하나만 출력한다. 키는 문항 id, 값은 정답 번호(1~4).

```json
{ "e6-sci-0001": 1, "e6-sci-0002": 3 }
```

정답이 모호하거나 확신이 없는 항목은 JSON 뒤에 따로 적는다.

## 적용

```bash
pnpm quiz blind-apply <문항파일> <답안.json>
```

불일치가 나오면 **정답 인덱스가 잘못 매겨진 것**이므로 해당 문항을 고친다.

## 한계 — 반드시 알고 쓸 것

교차 검증은 **정답 인덱스 오류만** 잡는다.
같은 모델이 만들고 같은 모델이 검증하면 **같은 오해는 그대로 통과한다.**
사실 오류는 이 단계에서 걸러지지 않으므로 `factcheck.md` 를 함께 돌려야 한다.
